# WMI 備賽計畫 — 通往 Legend 的三年

WMI 世界數學邀請賽的備賽規劃網站。純靜態，無建置步驟。

## 背景

2026 年於日本千葉舉行的 WMI Grand Final 取得**金獎**（當時小二）。目標是 2027（小三）與 2028（小四）再拿下金獎或鑽石獎，達成 **Legend Award** 的連續三年條件。

## 賽制重點

| 項目 | 內容 |
| --- | --- |
| 鑽石獎 Diamond | 各年級組前 **3%** |
| 金獎 Gold | 前 **12%** |
| Legend Award | 連續三年獲金獎或鑽石獎 |
| 出題語言 | **英文** |
| 涵蓋領域 | 計算、幾何、代數、數論、組合、推理 |
| 流程 | 每年 1–3 月各國選拔賽 → 7 月世界總決賽 |

資料來源：[WMI 官網](https://www.wminv.org/)、[中華數學協會](https://www.tmo.com.tw/)。

## 內容架構

- **遊戲規則** — 獎項比例與四個關鍵事實
- **三年級這一關** — 乘除進場、兩步題、英文句子變長
- **英文數學詞彙** — 32 條，分運算／數的性質／圖形／題目常用語四組，附遮罩自我測驗
- **六大領域怎麼練** — 各領域的練習重點
- **練習題** — 12 題自行編寫，英文出題、附中譯與解法
- **年度時程** — 從 8 月往回推的準備節奏
- **考古題** — 官方樣題（免費）與歷屆試題本（需購買）的取得方式
- **給爸媽** — 適配優於苦練，以及三件建議避開的事

## 練習題的版權說明

`app.js` 內的 12 題為**本專案自行編寫**，依 WMI 題型與三年級難度設計，**不是歷屆試題**。歷屆試題有版權，請透過中華數學協會官方管道購買。
